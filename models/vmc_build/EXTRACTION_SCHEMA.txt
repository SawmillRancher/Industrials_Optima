## Sources (SEC EDGAR only — the Vulcan IR website is blocked; its releases are the 8-K Ex. 99.1 exhibits)
- `filings.csv` lists every 10-K, 10-Q and earnings 8-K (Item 2.02) since 2006 with its EDGAR folder URL.
  Pre-Nov-2007 filings are under the legacy Vulcan CIK 103973; later under CIK 1396009.
- List a folder's documents: `curl -sS -H "User-Agent: $UA" <folder_url>index.json` (JSON `directory.item[].name`).
  The earnings release is the exhibit named like `*ex99*`, `*ex99-1*`, `*991*`, `exhibit99*`, or a `.txt`; open it.
- ALWAYS send header `User-Agent: Industrials Optima research research@industrialsoptima.dev` (SEC requires a UA;
  do NOT use any other email). Keep to <= 5 requests/second (add `sleep 0.3` between curls).
- Convert HTML to compact text (one table row per line, cells joined by ` | `):
  `python3 h2t.py file.htm > file.txt`  — then read/grep the text. Save raw files under `src/<period>/`.
- Optional cross-check: `vmc_facts.json` is the XBRL companyfacts dump (2009+), useful to verify GAAP totals.

## Basis rules
- Quarterly periods (Q1..Q4): use that quarter's earnings release ("Three Months Ended" columns), AS ORIGINALLY REPORTED.
  Q4 = the Q4 release's three-months column (do NOT derive Q4 = FY − 9M unless the release lacks a Q4 column; if derived, say so in `notes`).
- Annual periods (FY): use the Q4 earnings release twelve-month columns where available, plus the 10-K for anything the
  release lacks (cash-flow detail, balance-sheet detail, dividends per share, reserves, segment D&A, etc.).
  For FY2006–FY2012 (annual only) use that year's own 10-K (as originally reported) and its Q4 release.
- Units: USD millions to 1 decimal exactly as published (thousands → divide by 1,000 and keep 1 decimal);
  tons / cubic yards in millions; prices and per-ton figures in $ (2 dp); shares in millions; per-share in $.
- Signs: give costs/expenses as POSITIVE numbers where the field says "(positive)"; "signed" fields keep the sign of their
  effect on earnings / cash (income or inflow positive, expense or outflow negative).
- Use `null` when a figure is not published in the source for that period. Never estimate, never back-solve silently.
  If you compute a value (e.g. a sum of sub-lines), add a short note in `notes`.
- Every record must carry the source URLs used.

## Output
One JSON file per period in `data/` named `<period_key>.json`, period_key like `2013`, `Q1-13`, `Q4-25`, `Q2-26`.
Quarter records need sections `seg`, `is`, `ngaap`. Annual records need `seg`, `is`, `ngaap`, `cf`, `bs`, `extra`.
Also the `Q2-26` record gets `cf` and `bs` (six-months cash flow; balance sheet at 30-Jun-26).

## Self-checks before you finish each period (fix extraction errors, re-read the source)
- seg: Σ segment revenues + interseg_total (+ delivery_rev if separate) = is.total_rev (±0.2)
- seg: Σ segment GP = is.gp (±0.2);  Σ segment DDA + other_dda = total_dda (±0.2)
- is: gp − sag + gain_sale + other_op = op_earnings; op_earnings + nonop − interest = ebt; ebt − tax = cont_ops;
  cont_ops + disc_ops = net_earnings; net_earnings − nci = ni_vulcan  (±0.2 each)
- ngaap: ni_vulcan + ebitda_bridge_tax + interest + total_dda = ebitda_pub; ebitda_pub + Σ adj_items = adj_ebitda_pub (±0.3)
- cf sections sum to cfo / cfi / cff; cfo + cfi + cff = net_change; cash_begin + net_change = cash_end
- bs: total assets = total liabilities + total equity; components sum to subtotals
Report any check you could not make pass (with the reason) in `notes`.
